## Changelog

### ROM side

- Add Jelly browser from LineageOS
- Remove built-in calander app since too many crash

### IMS, VoLTE and SMS

- VoLTE is supported with one active SIM installed in either SIM1 or SIM2.
- Outgoing and incoming VoLTE calls, bidirectional audio and normal teardown have been validated.
- SMS sending and receiving have been validated on SIM1 and SIM2.
  - Functional SMS is supported; successful outgoing SMS may use the modem fallback path.
- SIM1 physical removal and reinsertion recovery has been validated.
- Concurrent dual-SIM/DSDS operation is not supported or validated.

### VoWiFi

- VoWiFi has been validated on one SM-M115F using Taiwan Mobile in a single-active-SIM configuration.
- Validated operations include:
  - outgoing call to Taiwan Mobile 188 with audible service audio;
  - incoming call with bidirectional audio and normal teardown.
- Other carriers, concurrent dual-SIM operation, emergency calling over Wi-Fi and inter-RAT handover remain unverified.

## Known Issues and Limitations

- Emergency calling is not validated.
- Concurrent dual-SIM/DSDS operation is not supported.
- The Wi-Fi Calling preference may reset after changing SIM identity.
- IPv6 tethering offload is broken; IPv4 hotspot works.
- Miracast may fail with some receivers. One Windows 11 laptop with Intel Wi-Fi 7 refused the connection.
  - Wi-Fi is limited to 2.4 GHz, so occasional brief interruptions may occur.
- Unlimited Google Photos storage is currently not working due to an upstream ROM issue.

## Installation

> [!IMPORTANT]
> A clean flash is required when upgrading from any previous build.

1. If the device was previously repartitioned, restore the stock partition layout by flashing the stock ROM, then flash TWRP through Odin.
2. In TWRP, open **Wipe → Advanced Wipe** and wipe:
   - Dalvik / ART Cache
   - Data
   - Internal Storage
   - Cache
3. Flash the ROM ZIP.
4. Reboot back into TWRP.
5. Optional: flash [[BiTGApps Mini](https://bitgapps.io/)](https://bitgapps.io) before the first system boot.
6. Reboot to system.

This is a Vanilla build and does not include Google apps.

### FBE Encryption / Decryption

Some recoveries include encryption/decryption addons that are incompatible with this ROM. Use only one of the supplied ZIP files when selecting the desired data-encryption mode:

- `Enable_FBE.zip` — enables file-based encryption.
- `Disable_FBE.zip` — disables file-based encryption.

Do not flash both ZIP files.

> [!WARNING]
> Switching between FBE and DFE requires **Format Data**.  
> A normal factory reset is not sufficient.  
> Formatting Data erases every file stored in internal storage.
