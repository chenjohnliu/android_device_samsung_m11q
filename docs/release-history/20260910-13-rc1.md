> [!WARNING]
> This is a release-candidate build for the Samsung Galaxy M11 (SM-M115F) only.
>
> It was tested with the M115FXXS5CWK3-derived firmware environment and SIM1 on Taiwan Mobile. Other models, firmware/baseband versions, CSCs, carriers, and SIM2/DSDS configurations are not validated.
>
> Back up your data and keep a complete stock firmware package available for recovery. Emergency calling has not been validated; do not rely on this build for emergency communications.

## Changelog

### Samsung IMS / VoLTE

- Integrated Samsung IMS compatibility support for Android 13.
- Validated SIM1 WWAN IMS registration under SELinux Enforcing.
- Validated outgoing and incoming VoLTE calls:
  - ringing and answer;
  - clear bidirectional speech;
  - normal teardown.
- Fixed SMS send/receive compatibility.
- Fixed SIM1 VoLTE recovery after physically removing and reinserting the SIM.
- Validated outgoing and incoming VoLTE calls and SMS after SIM1 hot-swap.
- Confirmed that `com.sec.imsservice` remains stable during the validated call paths.

SMS functionality is validated at the user level. The captured outgoing transaction used IMS-to-SGs/CS fallback after the carrier rejected final delivery over IMS, so pure IMS-SMS transport is not claimed.

## Not currently claimed or validated

- SIM2 / DSDS VoLTE
- Pure IMS-SMS delivery
- VoWiFi
- ViLTE
- Emergency calling
- Inter-RAT handover
- Other Samsung models, CSCs, carriers, or stock firmware versions
- Extended stress and long-duration call testing

## Known issues

- IPv6 tethering offload is not working; IPv4 hotspot/tethering works.
- Miracast interoperability is limited. One Windows 11 laptop with Intel Wi-Fi 7 could not establish a connection.
- This device supports only 2.4 GHz Wi-Fi, so wireless-display performance may be limited.

## Installation

1. Confirm that the device is an SM-M115F.
2. Back up all important data.
3. Install compatible stock firmware and TWRP if they are not already present.
4. In TWRP, use **Format Data** for this RC. Do not wipe EFS, modem, or persist.
5. Flash the ROM ZIP.
6. Reboot back into TWRP.
7. Optionally flash [BiTGApps Mini](https://bitgapps.io/).
8. Reboot to Android.

A clean flash is required for this release candidate. During development, persistent IMS/Telephony state left by experimental builds caused call failures even after the source changes were reverted. The exact contaminated `/data` item has not been identified.

### FBE Encryption / Decryption
Some recoveries, such as TWRP, may include built-in encryption/decryption addons that are not compatible with this ROM.
Use the ZIP files provided below to properly enable or disable FBE:

- `Enable_FBE.zip` - Enables file-based encryption (FBE).
- `Disable_FBE.zip` - Disables file-based encryption (DFE).

> [!WARNING]
> When switching between FBE and DFE, **Format Data is required**.
> A normal factory reset is not sufficient.
> Formatting data will erase all files stored in internal storage.
