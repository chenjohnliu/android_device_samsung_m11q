## Changelog

### ROM side

- Unofficial CherishOS 4.12 / Android 13 Vanilla build for Samsung Galaxy M11 (`SM-M115F`, `m11q`).
- Include the Jelly browser from LineageOS and remove the built-in Calendar app.
- Fix the stale VoWiFi status icon by reflecting the actual IMS registration transport.
- Improve SIM phone-number display through Android subscription APIs. A number can only be shown when the SIM or network provides it.
- Restore restricted microG signature spoofing, including modern `SigningInfo` support on user builds. The package-name and signing-certificate restrictions remain in place.
  - microG Self-Check has passed runtime validation on this build.
- Include the previously omitted framework, MMS-service and Telecom companion changes needed by the current source configuration.

### IMS, VoLTE and SMS

- Integrate the Samsung `M115FXXS5CWK3` IMS compatibility stack into CherishOS Android 13, with stock-derived native dependencies.
- Support one active IMS subscription installed in either SIM1 or SIM2.
  - VoLTE and VoWiFi calls have passed functional validation on both SIM slots, tested separately with one active SIM.
- SMS sending and receiving have been validated, including the Samsung-to-Android IMS SMS bridge.
- Retain the stock 128-second SIP Timer F and the Android 13 incoming-call and handover audio hooks.
- Complete the Telecom `com.sec.imsservice.PERMISSION` declaration for Samsung IMS audio control.
- Retain the emergency-capability bitmask correction and add its regression test. Ordinary IMS support must not falsely advertise emergency IMS capability.
- Concurrent dual-SIM/DSDS IMS operation is not supported or validated.

### VoWiFi

- VoWiFi calling and Wi-Fi/LTE handovers have passed functional validation on this Cherish build, with one active SIM tested in each slot.
- Validated handover coverage includes VoWiFi ↔ VoLTE transitions.
- Weak-signal departure from Wi-Fi preserved the ongoing call without disconnection. After returning to Wi-Fi coverage, the call switched back to VoWiFi after approximately two minutes in the tested scenario.
- Preserve Samsung's modem-led legacy IWLAN handover and Android's deferred Wi-Fi shutdown. The retired AP-assisted handover experiment remains disabled.
- Include global stock-profile-backed Wi-Fi Calling availability rather than the old Taiwan-specific framework restrictions.
  - Profile coverage does not guarantee provisioning or successful operation on every carrier.
- Brief audio pauses may occur during handover; no universal interruption-time guarantee is claimed.

### Earlier fixes and project history

- Earlier CherishOS releases introduced FM Radio fixes, support for both fingerprint sensor variants, FBE/recovery guidance, and storage, playback and Wi-Fi fixes. The [cumulative changelog](https://github.com/chenjohnliu/android_device_samsung_m11q/blob/m11q-volte/CHANGELOG.md) records when these changes were introduced; the validation scope for this build is listed above.

## Known Issues and Limitations

- Emergency calling, including emergency calls over Wi-Fi, remains unvalidated end to end.
- Concurrent dual-SIM/DSDS IMS operation is not supported.
- Other firmware/device variants, ViLTE and alternate audio accessories remain outside the reported validation scope.
- Wi-Fi Calling depends on carrier provisioning and a working connection to the carrier's ePDG. Results may differ between Wi-Fi networks.
- Returning to VoWiFi during an ongoing call may take time after Wi-Fi coverage is restored. The tested return took approximately two minutes; timing can vary with the network and signal conditions.

## Installation

> [!IMPORTANT]
> Back up your data and internal storage before a clean flash. When switching from another ROM, use **Format Data**; a normal Wipe alone can leave incompatible encryption state and cause a return to recovery.

1. If the device was previously repartitioned, restore the stock partition layout using the stock ROM, then install a compatible TWRP recovery through Odin.
2. For a clean installation or a switch from another ROM, use **TWRP → Wipe → Format Data**, enter `yes`, and wipe Dalvik / ART Cache and Cache as appropriate.
3. Flash the ROM ZIP intended for `m11q`.
4. If required by your recovery, reboot back into TWRP before flashing additional packages.
5. This is a Vanilla build. If you choose Google apps, flash a compatible Android 13 ARM64 GApps package before the first system boot. The framework also supports compatible microG packages; signature-spoofing support does not install microG automatically.
6. Reboot to system. Enable Wi-Fi Calling for the active SIM if desired and allow IMS registration to complete.

Use the flashable ROM ZIP attached to this release. GitHub's automatically generated **Source code** archives are not ROM packages.

### FBE Encryption / Decryption

The release includes these optional data-encryption add-ons:

- `Enable_FBE.zip` — enables file-based data encryption.
- `Disable_FBE.zip` — disables file-based data encryption.

Use an add-on only when its encryption setting matches your intended installation and the package is compatible with your build and recovery.

Do not flash both enable- and disable-encryption add-ons.

> [!WARNING]
> Changing between FBE and DFE requires **Format Data**. Formatting Data erases apps, settings and files in internal storage. Back up first.
