## Changelog
### ROM side
- Synced Cherish OS tiramisu branch
- Fixed Play Integrity issue (if we install GApps)

### Device side
- Fixed dt2w (double tap to wake)
- Fixed NFC

## Known Issues
- VoLTE is broken
  - Voice calls cannot be tested (VoLTE is required in Taiwan).
- SELinux Permissive
  - Can be spoofed by [Integrity Box](https://github.com/MeowDump/Integrity-Box) module
- FM Radio
- Fingerprint
- Data Encryption

## Install
1. Install Stock ROM & TWRP using Odin.
2. Flash ROM & reboot to TWRP again.
3. (Optional) Flash [BiTGApps Mini](https://bitgapps.io) & go to Essential -> Decrypt -> Reboot system.

## Note
- KernelSU-Next is supported by default. Install the [v3.3.0 manager APK](https://github.com/KernelSU-Next/KernelSU-Next/releases/tag/v3.3.0) to use it.
- Unlimited Google Photos storage is not working.
  - This is a ROM-side issue. I tried fixing it but failed (because I'm just a silly quokka 🦘).
- This is the initial version, and likely the last one.
  - It took me a lot of time. Maybe no updates for this since I am super busy with my job right now.
  - You can submit bugs if you find any device-related issues. I am new to this, but I will do my best to fix them.
