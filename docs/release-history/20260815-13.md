## Changelog
### Device Side
- 1080p recordings no longer stutter in the built-in player (portrait 1080p was excluded from hardware decoding).
- exFAT SD cards and USB OTG drives now mount instead of asking to be reformatted.
- KernelSU root grants survive a reboot again.

### Added
- Wireless display (Miracast) works — Settings > Connected devices > Cast. Wi-Fi can stay connected.

### Changed
- The kernel is now built from source on every build; the prebuilt kernel blob is gone.
- KernelSU Next is pinned to v1.1.1. **Use the v1.1.1 manager APK**

### Coming from an older build
- A clean flash (format data) is required if your current build predates FBE.
- TWRP cannot decrypt FBE, so use `adb sideload` or a microSD/OTG drive to flash add-ons.

## Known Issues
- VoLTE is broken
  - Note: Voice calls cannot be verified on my end, as VoLTE is mandatory in Taiwan.
- IPv6 tethering offload is broken; IPv4 hotspot works.
  - Doubt anyone actually uses this, but good to know!
- Miracast may fail with some receivers (one Windows 11 / Intel Wi-Fi 7 laptop refused the connection). Wi-Fi is 2.4 GHz only, so expect occasional brief hitches.

## Installation
1. Flash Stock ROM & TWRP via Odin.
2. Flash the ROM zip, then reboot back into TWRP.
3. (Optional) Flash [BiTGApps Mini](https://bitgapps.io) and reboot to system.

### FBE Encryption / Decryption
Some recoveries, such as TWRP, may include built-in encryption/decryption addons that are not compatible with this ROM.
Use the ZIP files provided below to properly enable or disable FBE:

- `Enable_FBE.zip` - Enables file-based encryption (FBE).
- `Disable_FBE.zip` - Disables file-based encryption (DFE).

> [!WARNING]
> When switching between FBE and DFE, **Format Data is required**.
> A normal factory reset is not sufficient.
> Formatting data will erase all files stored in internal storage.

## Notes
- KernelSU Next is supported out of the box. Install the [v1.1.1 Manager APK](https://github.com/KernelSU-Next/KernelSU-Next/releases#release-v1.1.1) to manage root access.
- Unlimited Google Photos storage is currently not working
  - This is an upstream/ROM-side issue. I tried to fix it but couldn't (just a silly quokka 🦘 doing my best).
